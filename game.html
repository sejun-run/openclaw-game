📖 게임 도움말

🎯 목표

  • 적 서버의 HP를 0으로 만들면 승리!
  • 내 서버 HP가 0이 되면 패배

🃏 카드 조작

  • 탭/클릭 → 카드 상세 정보
  • 드래그 → 핸드 카드를 필드에 배치
  • 필드 카드 드래그 → 적에게 공격

⚡ 마나 시스템

  • 매턴 최대 마나가 +1 증가 (최대 10)
  • 카드 배치에 마나 소모
  • 마나 부족 시 카드 배치 불가

⚔️ 전투

  • 배치된 카드는 다음 턴부터 공격 가능
  • 초록 테두리 = 공격 가능
  • 적 유닛이 없으면 직접 공격 가능
  • 연속 공격 시 콤보 보너스 발동!

🔗 시너지

  • Lambda + DynamoDB → 공격력 +15
  • Docker + K8s → 공격력 +10
  • EC2 + EBS → HP +30
  • Route 53 → 모든 아군 공격력 +5
